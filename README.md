# StatIQ One

Project documentation now lives in [`docs/`](./docs/README.md).

## Quick Start

1. Install dependencies:
   `npm install`
2. Set `GEMINI_API_KEY` in [.env.local](./.env.example) or your local env file.
3. Run the app:
   `npm run dev`
